# 5G-Channel-Coding-MATLAB
MATLAB simulations and research studies on 5G channel coding techniques

## Overview
This repository presents MATLAB-based research and simulation studies related to channel coding techniques used in 5G and beyond-5G wireless communication systems.

The work focuses on the analysis and performance evaluation of modern channel coding schemes for reliable wireless communication.

## Channel Coding Techniques

The research work includes studies related to:

- Polar Codes
- LDPC Codes
- Convolutional Codes
- Hybrid and joint channel coding approaches

## Research Context

Channel coding is an important component of modern wireless communication systems. In 5G New Radio (NR), different coding schemes are used for different types of communication channels.

This repository documents research-oriented MATLAB simulations and analysis related to these coding techniques.
