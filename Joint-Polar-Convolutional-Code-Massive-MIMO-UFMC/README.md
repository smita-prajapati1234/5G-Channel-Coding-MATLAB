# Joint 5G NR Polar Code-Convolutional Code Design for Massive MIMO-UFMC System

## Overview

This project presents MATLAB-based research and simulation work on a joint 5G NR polar code and convolutional code design for a Massive MIMO-UFMC wireless communication system.

The study investigates the performance of channel coding techniques in combination with UFMC and Massive MIMO technologies for reliable 5G wireless communication.

## Research Focus

The research combines:

- 5G NR Polar Codes
- Convolutional Codes
- Massive MIMO
- UFMC
- Wireless channel modeling
- Error-control coding
- BER performance analysis

## MATLAB Simulation

This project includes MATLAB simulation codes associated with the published research work.

The code is provided to document the simulation methodology and support reproducibility of the research results.

## Performance Analysis

The simulation studies investigate communication-system performance using parameters such as:

- Bit Error Rate (BER)
- Signal-to-Noise Ratio (SNR)
- Channel coding performance
- Massive MIMO configuration
- UFMC waveform performance
