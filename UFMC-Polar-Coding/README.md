# Simulation of UFMC-Based Massive MIMO with Polar Coding for 5G and Beyond Wireless Networks

## Overview

This project presents MATLAB-based simulation and performance analysis of a UFMC-based Massive MIMO system with 5G NR Polar Coding for 5G and beyond wireless communication networks.

The study investigates the combination of UFMC waveform, Massive MIMO, higher-order QAM, and Polar channel coding to improve the reliability and performance of wireless communication systems.

## Research Focus

The research investigates:

- UFMC waveform for 5G and beyond wireless networks
- Massive MIMO systems
- 5G NR Polar Coding
- Higher-order QAM modulation
- BER performance
- SNR performance
- Impact of Massive MIMO antenna array size
- Reliability improvement using channel coding

## Simulation Study

The system was developed and evaluated through simulation-based analysis.

The study considers the effect of antenna array size and modulation order on system performance and evaluates the benefits of incorporating Polar channel coding with UFMC in a Massive MIMO scenario.

## Key Performance Analysis

The research includes analysis of:

- Bit Error Rate (BER)
- Signal-to-Noise Ratio (SNR)
- QAM modulation
- Massive MIMO antenna configurations
- Polar-coded UFMC performance
- Spectral characteristics of UFMC and OFDM

## MATLAB Code

MATLAB simulation files associated with this research work are included in this project folder.

The code is provided for academic and research purposes to document the simulation methodology used in the study.
